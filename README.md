# Clinic previews

Private website concepts for outreach. Not indexed by search engines.

## Add a new clinic

1. Copy the `_template` folder.
2. Rename the copy to the clinic's name plus 4 random characters, e.g. `bright-smile-dental-7f3k`.
3. Edit `index.html` inside it:
   - Set the clinic's colours at the top (`--brand`, `--brand-dark`, `--brand-soft`).
   - Replace every `[BRACKETED]` placeholder with real details from their Instagram or Google profile.
   - Put their logo and photos in the same folder and swap the grey placeholders for `<img>` tags.
   - Use only real facts. Leave out anything you can't confirm (ratings, years, qualifications).
4. Upload the folder to this repo.
5. The preview is live in about a minute at:
   `https://<your-username>.github.io/clinic-previews/bright-smile-dental-7f3k/`

## Remove a clinic

Delete its folder. The link stops working within a minute or two.

## Notes

- Keep the "Website concept" banner on every preview.
- Take a preview down straight away if a clinic asks.
- This repo is public, so anyone browsing it can see the folder names.
